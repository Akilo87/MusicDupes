# Privacy policy

**MusicDupes does not collect, transmit or store any personal data.**

The application has no network access of any kind. It reads the audio files
in the folder you select in order to analyse them, and writes its analysis
results to a local cache on your own computer. Nothing leaves your device.

MusicDupes never modifies or deletes your files.

The local cache (`data\cache.db` next to the program, or under
`%LOCALAPPDATA%\MusicDupes` for the Microsoft Store version and wherever the
program folder is not writable) contains file paths, tags and acoustic
fingerprints of the files you scanned. You can delete it at any time via
*File → Clear analysis cache*. The settings file next to it
(`data\MusicDupes.ini`) remembers the last folder, the slider positions, the
language and the window size. Deleting the `data` folder removes both.

# Datenschutzerklärung

**MusicDupes erhebt, überträgt und speichert keine personenbezogenen
Daten.**

Das Programm hat keinerlei Netzwerkzugriff. Es liest die Audiodateien im
ausgewählten Ordner, um sie zu analysieren, und legt die Ergebnisse in einem
lokalen Zwischenspeicher auf deinem Rechner ab. Nichts verlässt das Gerät.

MusicDupes verändert und löscht niemals Dateien.

Der lokale Zwischenspeicher (`data\cache.db` neben dem Programm, bei der
Microsoft-Store-Fassung und überall dort, wo der Programmordner nicht
beschreibbar ist, unter `%LOCALAPPDATA%\MusicDupes`) enthält Dateipfade, Tags
und akustische Fingerabdrücke der gescannten Dateien. Er lässt sich
jederzeit über *Datei → Analyse-Cache leeren* entfernen. Die
Einstellungsdatei daneben (`data\MusicDupes.ini`) merkt sich den zuletzt
gewählten Ordner, die Reglerstellungen, die Sprache und die Fenstergröße.
Wer den Ordner `data` löscht, entfernt beides.
